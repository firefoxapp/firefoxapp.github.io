Installing Firefox

Follow these steps in order to get Firefox Portable running on your computer.

  1. 1Download the application here.
  2. 2Click the blue Download button.
  3. 3Click Download anyway.
  4. 4Open File Explorer and go to Downloads.
  5. 5Right-click the downloaded FirefoxBrowser.zip file and select Extract All, then click Extract.
  6. 6Press the Windows key, type Firefox, and open FirefoxPortable.exe.
